# Original gallery

16 original emitter projects and six original analytic white/alpha texture masks, authored for this repository. No vendor pack content is included or used to generate these assets.

The gallery definitions, editable projects, masks and their rendered GIF/PNG derivatives are released under CC0-1.0: https://creativecommons.org/publicdomain/zero/1.0/ . This dedication applies only to this gallery, not third-party dependencies or the rest of the repository.

- `fx/`: original effect definitions; texture IDs require the matching project assets.
- `projects/`: self-contained editable Author Studio JSON (embedded texture bytes).
- `textures/`: analytic masks generated by `../qa/create-textures.py` (Python + Pillow).
- `out/`: real 64px and 32px rerenders, not downsampled copies; PNGs contain every frame.
- `original-gallery.pak`: combined pack for Clone Lab. Original vendor-app compatibility is unverified.
- `manifest.json` and `render-receipts.json`: fixed seeds, capture settings and nonblank pixel checks.

Reproduce from the repo root:

```sh
python3 clone/qa/create-textures.py
node clone/qa/create-gallery.mjs
(cd clone && bun run build)
CLONE_CHROME=/path/to/chrome CLONE_PYTHON=python3 node clone/qa/render-gallery.mjs
```

Each 1.4-second capture has 21 frames at 15 fps. GIF centisecond timing rounds frame delays; use PNG frames for exact playback timing. Render evidence uses Linux Chrome software WebGL, not physical Windows certification.
